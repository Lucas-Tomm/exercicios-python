## Descrição

Este repositório reúne 25 exercícios introdutórios de Python sobre variáveis, condicionais,
estruturas de repetição e listas. Os exercícios estão organizados por assunto e versionados
com Git para acompanhar a evolução da atividade.

## Tecnologia utilizada

- **Linguagem:** Python
- **Versão:** 3.13.15

## Como executar

Com Python 3.13.15 instalado, abra um terminal na pasta do repositório e execute qualquer
arquivo com o comando abaixo:

```bash
python caminho/para/exercicio.py
```

Por exemplo:

```bash
python parte1-variaveis/ex01.py
```

Nos exercícios que solicitam dados, informe os valores quando o programa pedir.

## Índice dos exercícios

### Parte 1 — Variáveis, entrada e saída

1. `parte1-variaveis/ex01.py` — Exibe nome e idade.
2. `parte1-variaveis/ex02.py` — Calcula a soma de dois números.
3. `parte1-variaveis/ex03.py` — Calcula a área de um círculo.
4. `parte1-variaveis/ex04.py` — Converte Celsius para Fahrenheit.
5. `parte1-variaveis/ex05.py` — Calcula o valor total de uma compra.

### Parte 2 — Condicionais

6. `parte2-condicionais/ex06.py` — Informa se um número é par ou ímpar.
7. `parte2-condicionais/ex07.py` — Identifica o maior entre dois números.
8. `parte2-condicionais/ex08.py` — Classifica um número como positivo, negativo ou zero.
9. `parte2-condicionais/ex09.py` — Classifica a média de um estudante.
10. `parte2-condicionais/ex10.py` — Verifica se a idade permite votar.

### Parte 3 — Repetição com while

11. `parte3-while/ex11.py` — Exibe os números de 1 a 10.
12. `parte3-while/ex12.py` — Soma números até a entrada zero.
13. `parte3-while/ex13.py` — Solicita a senha até acertar.
14. `parte3-while/ex14.py` — Exibe a tabuada de um número.
15. `parte3-while/ex15.py` — Conta números positivos até a entrada zero.

### Parte 4 — Repetição com for

16. `parte4-for/ex16.py` — Exibe os números de 1 a 20.
17. `parte4-for/ex17.py` — Exibe os números pares de 2 a 20.
18. `parte4-for/ex18.py` — Soma os números de 1 a 100.
19. `parte4-for/ex19.py` — Calcula o fatorial de um número.
20. `parte4-for/ex20.py` — Faz uma contagem regressiva até 1.

### Parte 5 — Listas

21. `parte5-listas/ex21.py` — Exibe cinco números de uma lista.
22. `parte5-listas/ex22.py` — Soma os itens de uma lista.
23. `parte5-listas/ex23.py` — Encontra o maior valor de uma lista.
24. `parte5-listas/ex24.py` — Conta itens maiores que 10.
25. `parte5-listas/ex25.py` — Exibe uma lista na ordem inversa usando índices.
